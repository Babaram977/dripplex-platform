# `@dripplex/types`

Shared domain types, API response envelopes, auth contracts, and Zod validation schemas.

## Exports

- `.` — API types, auth types, user types, validation schemas
- `./validation/auth` — auth form schemas (`loginSchema`, `registerSchema`, etc.)

## Usage

```ts
import { loginSchema, type AuthTokens } from '@dripplex/types';
```
